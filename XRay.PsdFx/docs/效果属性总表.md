# 效果属性总表

> 代码位置：`src/XRay.PsdFx/Effects.cs` → `Project()`（一个大 switch，把描述符键赋给属性）。
> 本表与实现逐行核对过（2026-11），改代码时请同步更新此表。

## 0. 通用规则

- **一个类装所有效果**：`PsdEffect` + `Kind`（`PsdEffectKind`）区分十种效果。
  不适用于当前效果的属性为 `null` / `false`，不会抛异常。
- **`null` 的两种含义要区分**：`Noise` 这类 `float?` 属性，`null` = 文件里没有该键；
  `0` = 有键但值为 0。非可空属性（`Enabled`、`BlendMode`、`Opacity`…）永远有值。
- **每个效果都带 `Descriptor`**：任何未映射的键都可以 `effect.Descriptor.GetNumber("键")` 读到，
  或用便捷方法 `effect.GetNumber("ShdN")`。
- **单位归一化**：文件里不透明度/杂色是 `0~100` 的 `#Prc`，属性一律 `0~1`；
  渐变色标位置是 `0~4096` 的 `long`，属性是 `0~1` 的百分比。

### 所有效果共有的属性

| 属性 | 键 | 说明 |
|---|---|---|
| `Kind` | 块键（`DrSh`/`IrSh`/…） | 效果种类 |
| `Enabled` | `enab` | 该效果自己的勾选框；关闭的效果也会出现在列表里 |
| `BlendMode` | `Md  ` | 混合模式（浮雕时是"高光模式"） |
| `Opacity` | `Opct` | 不透明度 0~1（浮雕时是"高光不透明度"） |
| `Descriptor` | — | 原始描述符，全部键可读 |
| `FillType` | 见各效果 | 填充类型：`Solid` 颜色 / `Gradient` 渐变 / `Pattern` 图案；不填充的效果（阴影、浮雕、光泽）为 null |

## 10. 枚举对照

**`PsdBlendMode`**（28 种）：Normal, PassThrough, Dissolve, Darken, Multiply,
ColorBurn, LinearBurn, DarkerColor, Lighten, Screen, ColorDodge, LinearDodge,
LighterColor, Overlay, SoftLight, HardLight, VividLight, LinearLight, PinLight,
HardMix, Difference, Exclusion, Subtract, Divide, Hue, Saturation, Color, Luminosity

**`PsdStrokePosition`**：Outside / Inside / Center

**`PsdBevelStyle`**：InnerBevel / OuterBevel / Emboss / PillowEmboss / StrokeEmboss

**`PsdBevelTechnique`**：Smooth / ChiselHard / ChiselSoft

**`PsdGradientType`**：Linear / Radial / Angle / Reflected / Diamond / ShapeBurst

**`PsdGradientInterpolation`**：Classic / Perceptual / Linear

**`PsdGradientNoiseModel`**：Rgb / Hsb / Lab

## 11. `PsdGradient`（渐变，外发光/内发光/渐变叠加/渐变描边共用）

| 键 | 属性 | 说明 |
|---|---|---|
| `Nm  ` | `Name` | 预设名（已解本地化令牌，如 `$$$/…=锥形` → `锥形`） |
| `GrdF` | — | `Strt`实色 / `ClNs`杂点；杂点时 `Noise` 有值 |
| `Intr` | `Interpolation` | 平滑度（1024/2048/4096 → Classic/Perceptual/Linear） |
| `Clrs` | `ColorStops` | 色标列表，见下 |
| `Trns` | `AlphaStops` | 透明度标列表，见下 |
| `Type` | `Type` | 线性/径向/角度/反射/菱形/形状爆发 |
| `Angl` | `AngleDegrees` | 度 |
| `Scl ` | `Scale` | %（100 → 1.0） |
| `Rvrs` | `Reverse` | 反向 |
| `Algn` | `AlignWithLayer` | 与图层对齐 |
| `Ofst` | `OffsetXPercent` / `OffsetYPercent` | 偏移 % |
| `Smth` | `Smoothness` | 平滑度 % |

**色标 `PsdGradientColorStop`**：`Location`（0~1，文件 0~4096）、`Color`（PsdColor）、
`Midpoint`（0~1）。
**透明标 `PsdGradientAlphaStop`**：`Location`、`Opacity`（0~1）、`Midpoint`。

**杂点 `PsdGradientNoise`**：`Seed`（`RndS`）、`Roughness`（`Smth` 0~4096）、
`AddTransparency`（`ShTr`）、`Model`（`RndM`）、
`Minimum` / `Maximum`（`Mnm `/`Mxm ` 四通道 0~100，RGB + alpha）。

## 12. `PsdPatternPlacement`（图案，图案叠加/描边/浮雕纹理共用）

| 键 | 属性 |
|---|---|

| `phase` | `PhaseX` / `PhaseY` | 纹理相位偏移 |

## 13. `PsdContour`（等高线，投影/阴影/发光 TrnS、浮雕 TrnS+MpgS、Satin MpgS）

| 属性 | 说明 |
|---|---|
| `Name` | 预设名（已解本地化令牌）；回退直线时为 `"Linear"` |
| `Points` | 曲线点列表：`X`（0~255 输入）、`Y`（0~255 输出）、`Corner`（尖角） |
| `IsLinear` | 是否为两点直线 |

Photoshop 自带 30 种预设（`Presets/Contours/Contours.shc`），文件里以
`$$$/Contours/Defaults/<Key>=<本地名>` 引用；用户自定的等高线名字是任意字符串。
`PsdContour` 目前只给名字和点，不做预设归类（待做：`Token` + 30 种内置预设匹配）。
