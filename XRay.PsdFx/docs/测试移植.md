# 测试移植台账

原版 `XRay.Psd` 的测试资产：3 个工程、35 个文件、约 9000 行（xunit.v3）。
本仓库 `tests/XRay.PsdFx.Tests` 是 net45 对应物，随移植阶段逐批补全。

## 工具链

| 项 | 原版 | 本仓库 |
|---|---|---|
| 框架 | xunit.v3 4.0.1 | MSTest 2.2.8（net45 最后支持线） |
| 运行器 | Microsoft.Testing.Platform（父仓库 global.json） | VSTest（本仓库 `global.json` 覆盖） |
| 命令 | `dotnet test` | `dotnet test tests/XRay.PsdFx.Tests` |
| 测试语料 | `test_documents` 子模块 | 同一约定：`XRAY_TEST_DOCUMENTS` 或向上查找 `test_documents` |
| 语料缺失 | `Assert.Skip` | `Assert.Inconclusive`（计入“已跳过”） |

`global.json` 说明：父目录 `x-ray-others/global.json` 把测试运行器钉成 MTP，而 MTP 不支持 net45 的
MSTest 2.2。本仓库根的 `global.json` 用更近的作用域把它覆盖为 VSTest，**不改动父仓库**。

## 约定

- 原版 `[Fact]`→`[TestMethod]`、`[Theory]+MemberData`→单测试内循环（可读性优先），断言迁移：
  `Assert.Equal(expected, actual, precision)`→`Assert.AreEqual(..., delta)`、
  `Assert.Skip`→`Assert.Inconclusive`、`Assert.Same`→`Assert.AreSame`。
- 语料相关用例一律走 `Fixtures`，**无语料时必须是 Inconclusive 而不是通过**，避免假绿灯。
- 合成文档优先：能由 `PsdBuilder` 构造的用例不依赖语料，保证任何机器可跑。
