# 移植计划：XRay.Psd (net10) → XRay.PsdFx (net45)

> 目标：把原版 `XRay.Psd`（约 21,700 行、78 文件）翻译为 net45 / C# 7.3 版本，
> 并入本仓库。**现有公开 API 与行为不变**（已有其他项目调用），全部改动为加法。

## 目录结构与命名空间

- **文件夹镜像原版**（1:1 对照审查/diff）：`IO/`、`Imaging/`（含 `Icc/`）、
  `Descriptors/`、`Layers/`、`Rendering/`、`Resources/`、`Text/`、`Codecs/`；
  根目录放 Parser/Document/PsdTypes/Compat（对应原版根的 PsdParser/PsdDocument/PsdTypes）。
  现有文件已归位：IO 9 个、Descriptors 1 个、Layers 7 个。
- **命名空间保持扁平 `XRay.PsdFx`**：现有公开 API 已被其他项目引用，
  改命名空间是破坏性变更；文件夹只影响文件组织，不影响编译（SDK 项目通配）。

## 类型命名

- 文档类型原叫 `PsdEffectsDocument`（那时只管效果），已更名为 **`PsdDocument`**，
  与原版 `XRay.Psd.PsdDocument` 对齐——它接下来要长成像素/文字/渲染俱全的完整文档。
- **旧名不留兼容壳**：改名一次到位，无 `[Obsolete]` 别名、无泛型工厂残留，
  避免半新半旧的 API 表面。若外部旧代码报 CS0246，改成 `PsdDocument` 即可。
- 已删除的 `PsdDocumentCompatibility.cs` 与泛型 `PsdParser.Parse<T>` 属于同一决定，
  不要再加回来。

## 铁律

1. **不破坏现有调用方**：`PsdEffect`/`PsdDocument`/`PsdLayer`/`PsdColor`/
   `PsdRect`/`PsdColorMode` 等已有类型不改签名，只加成员；已实测的行为（效果属性
   映射、luni、全局光、FillType、lnkA/Algn）不许回退。
2. **零依赖**：原版核心也是零依赖（Png/Jpeg 编码器是自带的），net45 版同样不加包。
   SkiaSharp 文字渲染在原版里也是独立项目（`XRay.Psd.Text`），不在本次范围。
3. **C# 7.3 改写规则**（翻译时统一处理）：
   - `record` → 手写 class/struct（含 Equals/ToString）；`readonly record struct` → readonly 字段 struct
   - `init` → `internal set`；主构造函数 → 普通构造函数
   - `MathF.*` → `internal static class MathF` 垫片（Compat.cs）
   - `Math.Clamp` → `Compat.Clamp`；switch 表达式 → switch 语句；模式匹配 → if/is
   - `ReadOnlyMemory<byte>`/`Span<byte>`/`MemoryManager` → `byte[]` 切片拷贝
     （net45 无法消费 System.Memory）
   - `AsyncLocal<T>`（4.6 才有）→ `[ThreadStatic]`（库入口全是同步调用，语义等价）
   - `ObjectDisposedException.ThrowIf` → if + throw
   - 六进制大整数位运算、`stackalloc` 逐处检查

## 里程碑验收

- M1（阶段 0-5）：`PsdDocument` 增加像素/蒙版/组/资源能力，真实文件逐字节与原版对齐
- M2（阶段 6-9）：`PsdRenderer.Render(path, out Png)` 在测试语料上与原版输出逐像素一致（ICC 留 M3）
- M3（阶段 10-11）：ICC 色彩管理 + 全量测试绿

## 已知偏差（原版有、net45 版有意不同）

- PsdSource 窗口 = 拷贝而非内存映射零拷贝（net45 无 System.Memory）；大 PSB 慢但正确
- 并行度/取消走 ThreadStatic 而非 AsyncLocal（库入口均为同步 API）
- 文字渲染不做 SkiaSharp 版（原版也在独立项目里）；自带 PathRasterizer 版照常移植
